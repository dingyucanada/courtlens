产品的主要入口是 `/projects.html`，启动后只监听 `127.0.0.1`。视频会复制到本机工作区，正常保存的项目与历史可重开；草稿与未完成占位不能直接导出。默认成片无音轨，macOS 本机 `say` 可用时可选中文配音，两种模式均不保留原音。配音失败不暗中改成无声结果。它不是具备账号、多人隔离与计费的公网 SaaS。

真实 NBA 输入、真实云模型调用和 Windows 实机验证仍未完成。上述实现能力、测试通过和正式赛事条件是不同事项，不能互相替代；最终测试计数、实测环境与限制统一见 [最终验收报告](最终验收报告.md)。
